## Информация о сервере
**Crimson Coalition** -  это ванильный анархо-сервер для Minecraft (версия 1.21.11, IP: mc.crimson-coalition.ru:25800). Где присутсвует полная свобода действий не зависящая от доната: здесь можно спокойно строить, грабить, объединяться с другими игроками или действовать в одиночку — без доната, приватов и жёстких правил (читы, гриф разрешены).
